# PPT

这是启动时自带的基础技能。

1. 当前环境不能直接解析或生成二进制 `.pptx`。不要声称已经读取或导出了幻灯片文件。
2. 用户要做演示时，先确认受众、页数和每页要讲的一点，再写成按页分开的大纲。
3. 每一页包含：页标题、一句主信息、最多三个要点。用 `write_file` 写到 `/outputs`，路径用 `.md`。
4. 如果用户上传了 `.pptx`，说明还不能读取其中的页面，请用户粘贴大纲或导出成 PDF 后再处理。
