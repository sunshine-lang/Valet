# PDF

这是启动时自带的基础技能。

1. 用户上传的 PDF 在 `/uploads`。用 `ls` 确认路径，再用 `read_file` 读取抽出的正文。
2. 按页或按用户的问题摘录，不要编造文件里没有的句子、数字或页码。
3. 抽不出文字时，直接说明这是扫描件或没有文本层，不要假装读过。
4. 需要交给用户的整理结果用 `write_file` 写到 `/outputs`，并在对话里给出路径。
